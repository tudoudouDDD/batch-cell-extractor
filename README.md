# 批量提取表格指定单元格内容

批量提取 Excel 表格指定单元格内容的本地网页工具。支持批量读取 XLS、XLSX、CSV 文件，并按单元格地址提取数据。
例如批量提取同一种格式（表格内容完全相同）工作簿Sheet1中的E1单元格内容，批量导出为新表格。

## 功能

- 批量选择 Excel 文件或文件夹
- 指定工作表和单元格地址，例如 AA12、BZ103
- 支持 XLS、XLSX、CSV 文件
- 导出 XLSX 和 XLS 结果
- 浏览器本地处理文件
- 支持宽表，不需要横向展开整张表
